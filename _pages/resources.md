# Data & Resources

All resources from the Narrative Dynamics project are made available under the MIT License. We believe in open science and reproducible research, so we provide access to our experimental data, analysis code, and simulation tools.

## Datasets

Our experiments have generated rich datasets that capture how narrative elements spread through social networks. These datasets include:

- **Experimental Trial Data** - Records of participant interactions, adoption decisions, and narrative states over time
- **Survey Responses** - Pre- and post-experiment participant responses regarding narrative understanding
- **Network Configurations** - Descriptions of the social network structures used in experiments

All datasets are provided in both CSV format for easy analysis and as SQL dumps for more complex database operations.

[Access Datasets](/datasets/){: .btn .btn--primary}

## Code Repositories

Our research relies on several custom software tools, all of which are available as open-source repositories:

### Simulation Framework

Our agent-based simulation framework allows researchers to model narrative diffusion under various conditions. The framework includes:

- Agent models with configurable adoption thresholds
- Multiple social network topologies
- Tools for visualizing diffusion patterns
- Parameter optimization capabilities

[GitHub Repository](https://github.com/c4-lab/narrative-simulation){: .btn .btn--info}

### Analysis Tools

We've developed a suite of tools for analyzing experimental results and comparing them to model predictions:

- Scripts for processing raw experimental data
- Statistical analysis packages
- Visualization tools for network-based diffusion
- Model fitting and validation utilities

[GitHub Repository](https://github.com/c4-lab/narrative-analysis){: .btn .btn--info}

### Experimental Platform

The custom web-based platform used to conduct our experiments is also available:

- Interactive network visualization
- Real-time participant interaction
- Data collection and storage modules
- Administrative interface for experiment configuration

[GitHub Repository](https://github.com/c4-lab/narrative-platform){: .btn .btn--info}
